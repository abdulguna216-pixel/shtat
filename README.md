# ШТАТ — сайт по утверждённому референсу

## Запуск

Без установки зависимостей:

```sh
cd /Users/abdul/Desktop/штат/shtat-site
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Папка `dist` готова к статическому хостингу. Исходники HTML, CSS и JavaScript находятся в ней же; сборка не требуется. Использована семантическая HTML-разметка и отдельные JS-компоненты Navigation, Services, InformationDialog, FAQ, Process и RequestForm, без UI-библиотек. Шрифты подключены локально, лицензии в `dist/assets`.

## Референс

`design/reference.png` и `design/brief.md` — исходные материалы. Все заголовки, меню, список услуг, форма, FAQ и логотип набраны живым текстом. Иллюстрации — отдельные WebP-фрагменты исходного референса. Весь сайт не является картинкой. `scripts/extract-assets.py` документирует координаты извлечения сцен (исходник хранится в `design/reference.png`).

## Где редактировать

- `dist/index.html` — семантическая разметка, тексты секций, навигация, форма.
- `dist/styles.css` — адаптивная композиция и типографика.
- `dist/content.js` — ответы FAQ, контакты, политика и адрес обработчика.
- `dist/app.js` — отдельные компоненты взаимодействий.

## Обязательные данные до начала приёма заявок

1. Настоящие контакты и реквизиты оператора персональных данных.
2. Утверждённая политика обработки данных (`siteConfig.privacyPolicy`). Сейчас диалог прямо сообщает, что документ не утверждён.
3. Реальный HTTPS API (`siteConfig.requestEndpoint`), который проверяет данные на сервере, ограничивает частоту запросов и доставляет заявку получателю. Клиент отправляет JSON `{name, phone, service, consent}`. Успех показывается только при успешном HTTP-ответе с `{delivered: true}`. Токены и другие секреты должны находиться исключительно на сервере.
4. В FAQ добавлены ответы на все пять вопросов по запросу владельца. Ответы описывают направления работы и порядок согласования условий, без фиксированных сроков, цен и гарантий. Содержимое редактируется в `dist/content.js`.
5. Подтверждение сроков, географии, условий оформления, контроля и замены сотрудников. Непроверенные цифры и обещания, включая примерный телефон из макета, не скопированы.

**Сейчас форма не отправляет и не сохраняет персональные данные.** Валидный ввод вызывает честное сообщение об отсутствии получателя; фиктивного сообщения об успехе нет.

## Визуальные ограничения

- Исходный файл — сжатый растр 764 × 2058; отдельных исходных иллюстраций и файла оригинального шрифта нет. При широком экране детали графики мягче, чем у полноразмерных оригиналов.
- Заголовки — Oswald 700 с кириллицей и подстройкой пропорций. Точное совпадение начертаний с неизвестным шрифтом макета не заявляется.
- Сцены извлечены из утверждённого изображения; в hero и сцене формы применены маски, чтобы удалить попавшие в изображение элементы интерфейса и надписи. Эти участки немного отличаются по фактуре.
- Телефон в футере отсутствует; коммерческие и юридические неподтверждённые формулировки заменены согласно ТЗ. Новые секции не добавлены.
- Мобильная версия — адаптация той же композиции: типографика, изображение, список и этапы перестраиваются последовательно.

## Проверка

В браузере Chromium проверены ширины 320, 375, 390, 428, 768, 1024, 1440, 1920: без горизонтального переполнения и обрезанных строк заголовков. Проверены раскрытие меню, клавиатурный FAQ, переход услуги в форму, ошибки обязательных полей и телефона, согласие, отсутствие реальной отправки без интеграции, диалоги и reduced motion. Ошибок JavaScript и неуспешных запросов нет.
